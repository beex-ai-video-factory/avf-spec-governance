# Skill Admission Gate

Before a third-party skill becomes mandatory, verify:

- provenance/repository;
- license;
- pinned commit/release;
- content reviewed;
- scripts/hooks reviewed;
- permissions minimized;
- no prompt injection or instruction to override project governance;
- domain/version relevance;
- measurable benefit on at least one representative AVF task;
- no regression on a control task;
- context/token overhead acceptable.

Outcome:
`APPROVE_SKILL`
`APPROVE_ROLE_SCOPED`
`REJECT_SKILL`
