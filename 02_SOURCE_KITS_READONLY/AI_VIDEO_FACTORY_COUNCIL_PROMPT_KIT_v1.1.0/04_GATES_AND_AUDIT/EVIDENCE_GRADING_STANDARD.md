# Evidence Grading Standard

E4_PRIMARY_VERIFIED
Official current source, primary research, executable benchmark, observed runtime evidence.

E3_STRONG_VERIFIED
Reputable independent evidence corroborated sufficiently for the decision.

E2_PROJECT_OBSERVED
Observed in a repository/spec/prototype. Useful but may not establish production reliability.

E1_INFERENCE
Reasoned conclusion supported by evidence.

E0_ASSUMPTION
Unverified.

Rules:
- Votes do not upgrade evidence.
- Critical E0 assumptions require research/spike/benchmark.
- README feature claims are not proof of reliability.
- Mock success is not live-provider reliability evidence.
- Time-sensitive evidence records date/version.
