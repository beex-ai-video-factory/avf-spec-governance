# I11 — Documentation & Agent Handoff

Produce:
- README;
- architecture summary;
- public interface docs;
- local dev;
- test commands;
- config/secrets;
- failure/recovery;
- migration/version notes;
- ADR links;
- troubleshooting;
- "How a future coding agent should modify this repo";
- forbidden dependencies/non-goals.

Test the handoff:
give docs + frozen contracts to a fresh reviewer and ask it to explain the repo without reading implementation first.
Resolve ambiguities.
