# I03 — Test & Failure Plan

Design:
- unit tests;
- contract tests;
- integration tests;
- E2E role in integration harness;
- failure injection;
- restart/recovery tests;
- security tests;
- observability assertions;
- migration/backward-compatibility tests where relevant.

For every external side effect, include duplicate delivery/timeout/uncertain outcome scenarios.

Review by independent QA role.
