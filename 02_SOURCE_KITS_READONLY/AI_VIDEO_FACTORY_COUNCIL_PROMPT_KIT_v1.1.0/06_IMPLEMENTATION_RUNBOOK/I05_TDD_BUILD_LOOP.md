# I05 — TDD Build Loop

For the next approved build task only:

1. confirm RED tests;
2. implement minimum correct behavior;
3. make tests GREEN;
4. refactor without changing contract;
5. run relevant full suite;
6. record changes in implementation traceability;
7. stop for independent review.

Do not silently change frozen contracts.
Do not modify unrelated repositories.
Do not claim DONE before verification evidence.
