# Operating Principles

1. **Evidence before opinion.**
2. **Independent review before group synthesis.**
3. **No unilateral architectural changes.**
4. **Hard problems must receive solution attempts, not capability deletion.**
5. **Equal-or-better simplification is welcome; capability regression is not.**
6. **Software correctness is deterministic where possible.**
7. **AI supplies bounded intelligence, not hidden canonical state.**
8. **Contracts precede independent implementation.**
9. **Tests precede claims of completion.**
10. **A council vote never overrides a failing objective test.**
11. **Security/reliability blockers remain blockers until evidence resolves them.**
12. **Dissent is preserved, not edited out of the record.**
13. **A fresh-context auditor must challenge every proposed freeze.**
14. **Unknowns are registered and assigned a spike/benchmark, never silently assumed away.**
15. **No agent may mark its own work accepted.**
