# v1.1 Upgrade Notes

v1.0 already established the correct foundation:
independent roles, blind review, findings, proposals, voting, dissent, adversarial audit, skill governance and freeze gates.

v1.1 hardens the operating protocol with:
- explicit human gate after every round;
- protected capability baseline and capability-delta classification;
- requirement-to-owner-to-test traceability;
- E0–E4 evidence grades;
- formal cross-examination hearings;
- panel diversity;
- voting eligibility/quorum rules;
- objective evidence overriding votes;
- immutable/hashable raw role reviews;
- exact semantic-diff/change-ID enforcement;
- post-merge consistency audit;
- stronger Flow Track A / Track B equivalence requirements;
- stronger implementation handoff freeze gate;
- aligned C00–C07 prompts.

Use v1.1 rather than v1.0 for the first formal council session.
