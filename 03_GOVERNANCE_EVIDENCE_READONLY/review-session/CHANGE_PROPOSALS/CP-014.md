# Change Proposal: CP-014 — Unified FFmpeg Media Processing Pipeline, Video Normalization and Perceptual Hash Continuity Engine

**SOURCE_FINDINGS:** F-R04-005, F-R12-001, F-R12-002, F-R12-003, F-R12-004, F-R12-005, F-R12-006, F-R12-007, F-R12-008  
**TITLE:** Unified FFmpeg Media Processing Pipeline, Video Normalization and Perceptual Hash Continuity Engine  
**STATUS:** PROPOSED (C03 Solution Design Complete)  

---

## 1. Problem Statement
Media processing operations (container probe, transcoding, aspect ratio conform, keyframe extraction) are distributed across multiple repos without standard specs or perceptual continuity verification.

---

## 2. Current Specification Baseline (v0.9.0)
The v0.9.0 specification lacks formal schema definitions, explicit state boundaries, and robust error/concurrency semantics for this domain.

---

## 3. Proposed Specification Changes (Option A vs Option B)

### OPTION_A: Strongest Practical Solution (Recommended)
Containerized FFmpeg worker service with S3/MinIO chunked streaming and automated perceptual hash indexing.

**Exact Architectural Changes:**
Standardize R12 Media service pipeline: 1. FFprobe container validation; 2. Transcode to standardized H.264/MP4 faststart (1080p/4K @ 24/30fps); 3. Keyframe extraction at 0.5s intervals; 4. Compute blockhash/pHash perceptual hashes for continuity comparison in R04.

### OPTION_B: Credible Alternative / Trade-off Analysis
Client-side WebAssembly media transcoding.

---

## 4. Impact Analysis & System Invariants

- **INVARIANTS_AFFECTED:** INV-001, INV-014
- **CONTRACTS_AFFECTED:** R12_MEDIA.md, R04_ASSETS_CONTINUITY.md
- **REPOS_AFFECTED:** R04_ASSETS_CONTINUITY, R11_QC, R12_MEDIA
- **SECURITY_EFFECT:** Enforces media container sandboxing (disabling FFmpeg network protocols and dangerous demuxers).
- **RELIABILITY_EFFECT:** Guarantees consistent, broadcast-ready video formats across all provider outputs.
- **OPERABILITY_EFFECT:** Provides deterministic operational visibility and predictable error recovery.
- **TESTABILITY_EFFECT:** Enables hermetic testing with isolated schemas and mock simulators.

---

## 5. Capability Preservation Proof
Strengthens C-11 (Media Assembly & Normalization) and C-09 (Asset Continuity).

## 6. Migration, Testing & Rollback Plan

- **BACKWARD_COMPATIBILITY:** Backward compatible; introduces versioned schemas and additive contracts.

- **ROLLBACK_PLAN:** Revert to raw provider media passthrough.
